# なろうReader

「小説家になろう」の各話URLを入力し、本文を読みやすい画面で表示する個人用Webリーダーです。

## 主な機能
- URLから本文を取得
- 前話 / 次話
- 横書き / 縦書き切替（縦書きは右から左へ横スクロール）
- 文字サイズ・行間・本文幅
- 紙 / 白 / ダークテーマ
- スクロール位置の自動保存
- 最近読んだ話の履歴
- ブラウザ標準の日本語読み上げ
- iPhoneホーム画面追加向けPWA設定

## 起動
Node.js 20.9以降を推奨。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

## 公開について
Next.js のAPIルートを使って本文を取得するため、静的ファイルだけのHostingでは動きません。Firebaseで公開する場合は、Next.jsを実行できる構成（Firebase App Hosting等）を使います。

## データの扱い
本文はサーバー側で都度取得し、このアプリのデータベースへ保存しません。表示設定・読書履歴・スクロール位置は端末のlocalStorageだけに保存します。

## 注意
- 対応URLは `https://ncode.syosetu.com/nxxxxxx/123/` 形式の各話ページです。
- 小説家になろう側のHTML構造変更により本文抽出ロジックの更新が必要になる場合があります。
- サイト側の規約・アクセス負荷に配慮し、個人利用を前提にしてください。
